# 🏐 Sistema de Replay Buffer para Quadra de Vôlei

Sistema automatizado para capturar e comercializar replays de jogadas de vôlei. Captura continuamente os últimos minutos de jogo e salva quando um botão é acionado.

## 🎯 Funcionalidades

- ✅ Captura contínua de vídeo com buffer circular
- ✅ Suporte para múltiplas câmeras simultâneas
- ✅ Acionamento via botões físicos (placa arcade USB)
- ✅ Upload automático para servidor
- ✅ Sistema de comercialização de clipes
- ✅ Limpeza automática de arquivos antigos

## 📋 Requisitos

### Hardware
- Câmeras IP ou webcams USB
- Placa USB Arcade (opcional, para botões físicos)
- Botões de acionamento
- Computador com mínimo 8GB RAM

### Software
- Python 3.8+
- PHP 7.4+ (para upload)
- OpenCV
- Git
